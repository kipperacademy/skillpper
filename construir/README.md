# construir

Projetos mínimos executáveis para aprender programação com decisões, implementação e depuração.

```sh
npx skills add kipperacademy/skillpper --skill aprender construir
```

Comece com `/construir um cache de produtos com Redis`, ou aceite um experimento proposto por
`/aprender`. Os checkpoints tornam o conceito observável e os comentários dentro do código
orientam a parte que você implementa. A skill prepara o código periférico, registra a ajuda
e preserva a retomada. Instalação e passagem automática dependem do suporte do agente.
Preserve a pasta `shared` ao copiar o pacote.

A construção local é gratuita. O MCP da Kipper exige acesso de membro pagante. Concluir um
projeto não concede automaticamente uma Conquista nem equivale a uma avaliação oficial.
Validação pedagógica com alunos continua em andamento.

Base pedagógica: [teach, de Matt Pocock](https://github.com/mattpocock/skills/tree/main/skills/productivity/teach).
O aviso MIT da referência está em [THIRD-PARTY-NOTICES.txt](./THIRD-PARTY-NOTICES.txt).

Este pacote é gerado a partir das fontes mantidas pela Kipper Academy; mantenha os contratos
comuns sincronizados nas duas skills ao publicar uma nova versão.
