# aprender

Estudo guiado de programação com explicações, perguntas, múltipla escolha e pequenos desafios.

```sh
npx skills add kipperacademy/skillpper --skill aprender construir
```

No seu agente, comece com `/aprender cache com Redis`. A skill adapta a atividade às respostas
e salva a retomada local. Quando um projeto ajudar, propõe passar para `/construir` após sua
aceitação. A invocação automática entre skills depende do agente; as duas também funcionam
separadamente. Preserve a pasta `shared` ao copiar o pacote.

O estudo local é gratuito. O MCP da Kipper exige acesso de membro pagante e usa somente as
ferramentas disponíveis. Busca e correção de questões oficiais, revisões, provas e Conquistas
ainda não fazem parte desta distribuição. Validação pedagógica com alunos continua em andamento.

Base pedagógica: [teach, de Matt Pocock](https://github.com/mattpocock/skills/tree/main/skills/productivity/teach).
O aviso MIT da referência está em [THIRD-PARTY-NOTICES.txt](./THIRD-PARTY-NOTICES.txt).

Este pacote é gerado a partir das fontes mantidas pela Kipper Academy; mantenha os contratos
comuns sincronizados nas duas skills ao publicar uma nova versão.
