## Recommended third-party skills

A curated index of skills and collections created and maintained by other authors. These projects are installed separately from Skillpper; each project's repository is the source for its documentation, requirements, license, and updates.

| Project | Author | What it helps with | Installation |
| --- | --- | --- | --- |
| [IP as Logo](https://github.com/s1dashu/ip-as-logo-skill) | [s1dashu](https://github.com/s1dashu) | Create simple, rounded mascot logos with an image-generation agent. | `npx skills add https://github.com/s1dashu/ip-as-logo-skill` — see the [requirements](https://github.com/s1dashu/ip-as-logo-skill#agent-compatibility). |
| [Skills for Real Engineers](https://github.com/mattpocock/skills) | [Matt Pocock](https://github.com/mattpocock) | A collection for clarifying requirements, planning changes, test-driven development, debugging, and software design. | `npx skills add https://github.com/mattpocock/skills` — follow the repository's [installation guide](https://github.com/mattpocock/skills#installation-30-second-setup), including its setup skill. |
| [gstack](https://github.com/garrytan/gstack/tree/main) | [Garry Tan](https://github.com/garrytan) | A collection of workflows for product planning, design reviews, code reviews, browser QA, and releases. | Follow the project's [setup instructions](https://github.com/garrytan/gstack/tree/main#install--30-seconds) for your agent; gstack includes tooling that requires its own setup. |
| [find-skills](https://www.skills.sh/vercel-labs/skills/find-skills) | [Vercel Labs](https://github.com/vercel-labs) | Discover and install agent skills from the open ecosystem by domain, task, or keyword. | `npx skills add https://github.com/vercel-labs/skills --skill find-skills` — see documentation on [skills.sh](https://www.skills.sh/vercel-labs/skills/find-skills). |
| [grill-me](https://www.skills.sh/mattpocock/skills/grill-me) | [Matt Pocock](https://github.com/mattpocock) | Interview the developer to expose hidden requirements, constraints, and trade-offs before implementation. | `npx skills add https://github.com/mattpocock/skills --skill grill-me` — see guide on [skills.sh](https://www.skills.sh/mattpocock/skills/grill-me). |
| [tdd](https://www.skills.sh/mattpocock/skills/tdd) | [Matt Pocock](https://github.com/mattpocock) | Test-driven development with vertical slices, behavior-focused tests at pre-agreed seams, and red-green-refactor cycles. | `npx skills add https://github.com/mattpocock/skills --skill tdd` — see guide on [skills.sh](https://www.skills.sh/mattpocock/skills/tdd). |
| [improve-codebase-architecture](https://www.skills.sh/mattpocock/skills/improve-codebase-architecture) | [Matt Pocock](https://github.com/mattpocock) | Surface architectural friction in churned files and propose module-deepening refactors for testability. | `npx skills add https://github.com/mattpocock/skills --skill improve-codebase-architecture` — see details on [skills.sh](https://www.skills.sh/mattpocock/skills/improve-codebase-architecture). |
| [prototype](https://www.skills.sh/mattpocock/skills/prototype) | [Matt Pocock](https://github.com/mattpocock) | Build throwaway logic walkthroughs or multi-variation UI prototypes to answer design questions. | `npx skills add https://github.com/mattpocock/skills --skill prototype` — see details on [skills.sh](https://www.skills.sh/mattpocock/skills/prototype). |
| [Graphify](https://github.com/Graphify-Labs/graphify) | [safishamsi](https://github.com/safishamsi) | Converts codebases into structured knowledge graphs for zero-token AST code navigation. | `pip install graphifyy && graphify install` — follow the installation guide at [Graphify-Labs/graphify](https://github.com/Graphify-Labs/graphify). |
| [OpenSpec](https://github.com/Fission-AI/OpenSpec) | [Fission-AI](https://github.com/Fission-AI) | Formal specification framework for capturing requirements, contracts, and architecture before agent code generation. | `npm install -g @fission-ai/openspec@latest` or `brew install openspec` — follow the setup guide at [Fission-AI/OpenSpec](https://github.com/Fission-AI/OpenSpec). |
| [ai-memory](https://github.com/akitaonrails/ai-memory) | [Fabio Akita](https://github.com/akitaonrails) | Local SQLite/FTS5 memory daemon for session indexing, cross-agent handoffs, and long-term context retention. | Follow setup and compilation instructions at [akitaonrails/ai-memory](https://github.com/akitaonrails/ai-memory). |
